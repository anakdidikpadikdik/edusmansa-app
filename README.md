# 🏫 EduSmansa — Asisten Digital & Smart Schedule SMAN 1 Sumedang

Aplikasi Web Progressive (PWA) Asisten Sekolah Digital cerdas berbasis AI untuk SMAN 1 Sumedang. 

## 🚀 Fitur Utama
- 📅 **Jadwal Pelajaran Interaktif (36 Kelas):** Cek jadwal real-time lengkap dengan timer jam pelajaran & widget status live.
- 🤖 **Hybrid AI Chatbot (Google Gemini & Local Engine):** Asisten pintar yang menjawab pertanyaan seputar jadwal, guru, dan tata tertib sekolah.
- ⚙️ **AI Schedule Studio (CP-SAT Solver):** Engine pembuat jadwal sekolah bebas bentrok menggunakan Google OR-Tools.
- 📱 **Progressive Web App (PWA):** Dukungan penuh Mode Offline tanpa kuota internet.
- 👤 **Portal Guru & Direktori:** Jadwal mengajar guru serta lini masa aktivitas.

## 🛠️ Spesifikasi Teknis
- **Frontend:** Native HTML5, CSS3 Modern (Bento/Glassmorphism), Vanilla JavaScript.
- **Backend AI/Solver:** Python (Flask, Google OR-Tools, Google Generative AI API).
- **Deployment:** Netlify (Frontend) & PythonAnywhere / Cloud (Backend).
